# Portfólio — Gabriel Pedreira

Site pessoal: desenvolvimento de software, jogos e arte (ilustração, concept art, animação e escultura).

🌐 **https://portifoliogabrielpedreira.com**

## O diferencial
Uma aranha-saltadora que eu desenhei e animei vive no site: desce pela teia e acompanha a leitura,
aponta para os trabalhos, cai se você cortar a teia, fica brava, aceita cafuné e depois passeia pelas paredes.
Tudo em JavaScript puro, com spritesheets desenhados frame a frame e uma pequena máquina de estados (`js/spider.js`).

## Stack
HTML, CSS e JavaScript puros — sem framework, sem build. Textos em PT/EN (`js/i18n.js`),
conteúdo em `js/data.js`.

## Rodar localmente
Abra `index.html` no navegador. Para ver a aranha na hora: `index.html?aranha=0`.
